# Cifrari di Cesare e Vigenère

Laboratorio interattivo di crittografia classica realizzato in **Mathematica**.
Progetto del corso di Matematica Computazionale, Laurea Magistrale in Informatica, Università di Bologna (2026). Voto: **30 e lode**.

## Contenuto

- **Teoria** sui cifrari di Cesare e Vigenère, spiegata passo dopo passo
- **Interfacce interattive** per cifrare e decifrare messaggi
- **Esercizi** per gli studenti, con verifica delle risposte

| File | Descrizione |
| --- | --- |
| `CrittografiaArcaica.m` | Pacchetto Mathematica con i cifrari e le interfacce |
| `Laboratorio_Crittografia_Arcaica.nb` | Notebook con teoria ed esercizi |

## Come usarlo

1. Apri `Laboratorio_Crittografia_Arcaica.nb` con Mathematica 14 o superiore.
2. Tieni `CrittografiaArcaica.m` nella stessa cartella.
3. Esegui il notebook dall'inizio (Valutazione → Valuta notebook).
